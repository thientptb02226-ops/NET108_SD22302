# Test Command (/test)

When invoked, execute the relevant test command based on the active directory:
- For `Trello-Clone-Frontend`: `npm run test -- --run`
- For `Trello-Clone-Backend`: `npm test`
- For `Trello-Clone-MCP`: `npm test`
- For `Trello-Clone-AI-RAG`: `pytest`

If any tests fail, analyze the stack trace and fix the implementation or test assertions immediately.
