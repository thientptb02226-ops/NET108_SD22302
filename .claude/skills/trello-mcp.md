# Trello MCP Skill

Allows Claude to invoke Trello board management tools directly:
- **`trello_list_boards`**: Read active boards to get context on project tasks.
- **`trello_create_card`**: Create a ticket when identifying an architectural debt or unassigned feature.
- **`trello_move_card`**: Move cards across lists to reflect real-time progress while coding.
- **`trello_rag_search`**: Search historical board context before asking the user redundant questions.
