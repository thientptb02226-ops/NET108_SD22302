# Project Roadmap & Milestones

### Phase 1: Core Foundation (MVP)
- [ ] Database schema design (Users, Workspaces, Boards, Lists, Cards) in `Trello-Clone-Backend`.
- [ ] Authentication (JWT + Refresh Tokens, Google OAuth).
- [ ] Interactive Kanban board with drag-and-drop in `Trello-Clone-Frontend`.
- [ ] Real-time updates via WebSockets (Socket.io).

### Phase 2: AI Enhancements (MCP & RAG)
- [ ] MCP Server for automated agent interaction with boards (`Trello-Clone-MCP`).
- [ ] Semantic vector search & RAG pipeline (`Trello-Clone-AI-RAG`).
- [ ] Embeddable Chatbot interface (`Chatbot-Frontend`).

### Phase 3: Multi-Platform Clients
- [ ] Mobile app with offline sync (`Trello-Clone-Mobile`).
- [ ] Desktop app with native system notifications (`Trello-Clone-Desktop`).
- [ ] Production infrastructure with Docker Compose & Kubernetes (`Trello-Clone-Infra`).
