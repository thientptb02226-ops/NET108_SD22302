# .claude — Claude Code Agent Configuration

This directory manages all commands, hooks, execution plans, safety policies, references, rules, and skills specific to **Claude Code CLI** operating in this project.

## Directory Structure
- `commands/`: Custom command prompts for fast agent shortcuts (e.g. review, test, sync).
- `hooks/`: Lifecycle hooks triggered before or after agent code operations.
- `plans/`: Strategic roadmaps, milestones, and agent task breakdowns.
- `policies/`: Multi-agent file locking, security, and read/write access policies.
- `references/`: Architecture specs, schema references, and API contracts.
- `rules/`: Strict coding standards, TypeScript conventions, and git workflow.
- `skills/`: Custom tooling scripts or prompt routines.
