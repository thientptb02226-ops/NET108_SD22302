# Rule: Roadmap Sync

> **Source**: Code Web Không Khó — Agent Hub

## 1. Nguyên tắc cốt lõi
- Luôn giữ `docs/03-san-pham/roadmap.md` và changelog phản ánh đúng thực tế dự án.
- Sau khi hoàn thành một tính năng (đã verify chạy được), Agent tự động đánh dấu hoàn thành và ghi log vào changelog.

## 2. Trigger
- **Trigger 1**: Code xong 1 tính năng -> Checkbox `[x]` trong `roadmap.md` và ghi ngày hoàn thành.
- **Trigger 2**: User đưa ra ý tưởng mới -> Thêm vào phần Backlog / Future Scope trong `roadmap.md`.
