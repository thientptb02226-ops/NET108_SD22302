# Rule: Docs Placement

> **Source**: Code Web Không Khó — Agent Hub

## Cấu trúc chuẩn của thư mục `docs/`
Mọi file markdown tài liệu phải được sắp xếp đúng nhóm:
- `docs/01-tong-quan/`: Giới thiệu dự án, mục tiêu, workflow tổng thể.
- `docs/02-ky-thuat/`: Kiến trúc hệ thống (`architecture.md`), API specs, database schema.
- `docs/03-san-pham/`: Roadmap sản phẩm (`roadmap.md`), PRD, User stories.
- `docs/04-van-hanh/`: Hướng dẫn deploy, checklist an toàn, runbooks khi gặp sự cố.

> **Ngoại lệ**: Chỉ `AGENTS.md`, `CLAUDE.md`, `README.md` được phép nằm ở thư mục gốc.
