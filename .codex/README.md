# .codex — OpenAI Codex / CLI Agent Configuration

This directory contains instructions, operational policies, and custom prompts tailored for **OpenAI Codex / CLI agents** collaborating in this repository.

## Directory Structure
- `commands/`: Execution scripts and generation commands.
- `hooks/`: Pre/post action validation routines.
- `plans/`: Execution roadmaps for backend and data layer tasks.
- `policies/`: Workspace boundary rules to prevent conflicts with Claude Code CLI.
- `references/`: Database schemas, API routes, and RAG contracts.
- `rules/`: Backend coding and architecture standards.
- `skills/`: Custom agent analytical capabilities.
