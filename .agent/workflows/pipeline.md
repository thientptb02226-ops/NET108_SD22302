# Agent Pipeline Workflow

1. **Step 1: Feature Proposal**:
   - Create task or review backlog.
   - Outline interface in `docs/api/`.
2. **Step 2: Concurrent Execution**:
   - Claude Code implements Frontend views in `Trello-Clone-Frontend`.
   - Antigravity / Codex implements Backend routes in `Trello-Clone-Backend` and tools in `Trello-Clone-MCP`.
3. **Step 3: Integration & Testing**:
   - Run end-to-end verification.
   - Execute test suites across affected packages.
