# .agent — Antigravity Agent Configuration

This directory contains workspace rules, custom skills, and execution workflows for **Antigravity**.

## Overview
Antigravity operates as the master orchestrator in this monorepo, capable of:
- Launching subagents for isolated tasks (e.g. specialized frontend / backend builders).
- Harmonizing code between Claude Code CLI, Codex CLI, and human developers.
- Monitoring build pipelines and git activity across all sub-projects.
