# Antigravity Orchestration Rules

1. **Role as Master Coordinator**:
   - Mediate conflicts between CLI agents.
   - Maintain `AGENTS.md` and keep shared interface docs in `docs/` accurate and synchronized.
2. **Commit Tagging**:
   - Commits by Antigravity should use `[agent:anti] <type>(<scope>): <summary>`.
3. **Safe Execution**:
   - Run tests before finalizing major refactoring across packages.
